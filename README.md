# 恋爱占有欲指数测试 · 你的占有欲有多强

付费移动端 H5 娱乐测验。18 道原创 Likert 题，六维画像 + 占有欲指数 + 六档锐评。

## 在线地址

https://zengpenghui420-glitch.github.io/possessiveness/

## 产品要点

| 项 | 说明 |
|---|---|
| 题目 | 18 题 · 五级自评（完全不像我 → 非常像我） |
| 维度 | 查岗脉冲 / 醋意电压 / 时间圈地 / 数字越界 / 确认饥渴 / 分离紧绷 |
| 结果 | 占有欲指数 + 档位 + 主导倾向 + 六维雷达 + 特征表现 + 边界小建议 |
| 订单号 | 小红书「我的订单」里复制。只接受 `P` + 18 位。重复块、逐位 ±1 的序列和 19 位号码提示「订单号格式不对」，不会开始。格式通过后立即开始。 |
| 提示 | 第一次开始：「验证成功，还可以测 2 次」。再测一次后是「还可以测 1 次」，然后「这是最后一次」。三次之后同一订单号仍可进入，提示「验证成功」。 |
| 不改提示 | 中途刷新、继续这一次、结果刷新、查看上次结果，都不改这次提示。 |
| 订单请求 | 不为订单号请求 `*.vercel.app`，也不对 Mantle 的 `orders` 做创建、读取或加减。页面不展示 paid 字段。 |
| 已发出的访问码 | 仍走本页原来的 vault：`POST /redeem` `{quiz:"poss",code}` 扣次，`GET /get?quiz=poss&code=` 只读。剩余次数以 vault 返回为准。页面不展示这套入口。 |
| 重新测试 | 订单号再开始一次；访问码仍是清会话后再提交 |
| 查看上次 | 仅读本机缓存，不改订单提示，访问码也不扣次 |
