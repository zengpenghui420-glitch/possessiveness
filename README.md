# 恋爱占有欲指数测试 · 你的占有欲有多强

付费移动端 H5 娱乐测验。18 道原创 Likert 题，六维画像 + 占有欲指数 + 六档锐评。

## 在线地址

https://zengpenghui420-glitch.github.io/possessiveness/

## 产品要点

| 项 | 说明 |
|---|---|
| 题目 | 18 题 · 五级自评（完全不像我 → 非常像我） |
| 维度 | 查岗脉冲 / 醋意电压 / 时间圈地 / 数字越界 / 确认饥渴 / 分离紧绷 |
| 结果 | 占有欲指数 + 档位 + 主导倾向 + 六维雷达 + 特征表现 + 边界小建议 |
| 订单号 | 小红书「我的订单」里复制。一单一测最多 3 次。新一次答题扣 1 次；同一次里中途刷新、继续、结果刷新只读不扣；再测才再扣。第 4 次拒绝，已有结果还在。 |
| 订单接口 | `POST /order/redeem` `{quiz:"poss",orderId}` 扣次；`GET /order/get?quiz=poss&orderId=` 只读。页面不展示接口里的 paid 字段。 |
| 已发出的访问码 | 仍走本页原来的 vault：`POST /redeem` `{quiz,code}`、`GET /get?quiz=&code=`。页面不展示这套入口。 |
| 重新测试 | 订单号再扣 1 次；访问码仍是清会话后再提交 |
| 查看上次 | 仅读本机缓存，不扣次 |
